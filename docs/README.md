# Project Documentation Directory

This directory contains technical documentation, domain specifications, and operational guides for **SentinelEye**:

- `DATA.md` — Data sourcing, satellite sensor specifications, band mapping, and preprocessing (Maintained by Anuj).
- `LLM_SCHEMA.md` — Facts Dictionary schema mapping, GBNF grammar definition, and hallucination-mitigation rules (Maintained by Priyanshu).
- `INTEGRATION.md` — Concrete integration checklist, module API contracts, and integration risk registry (Maintained by Amritanshu).
- `DEMO_FALLBACK.md` — Stage demo contingency plan, replay mode instructions, and recovery procedures (Maintained by Amritanshu).
- `ARCHITECTURE.md` — System architecture and data flow diagrams.
